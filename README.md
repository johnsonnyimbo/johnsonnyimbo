## 👨‍💻 About Me

Hi, I'm **Johnson Nyimbo**, a Computer Science student passionate about turning data into stories that people can understand and use.

I believe data is more than rows, columns, and numbers. Behind every dataset are patterns to uncover, questions to investigate, and insights waiting to be discovered.

Through projects in football analytics, housing data cleaning, and COVID-19 analysis, I'm building my skills in data analytics and business intelligence using **Power BI, SPSS, SQL/PostgreSQL, Excel, and Tableau**.

My approach is simple:

**Ask meaningful questions → Explore the data → Find the story → Communicate the insights.**

I'm also developing my technical foundations in Python and data engineering as I continue growing as an analyst.

- 📊 **Data Analytics:** Data exploration, cleaning, analysis, and reporting

- 🗄️ **Databases:** SQL and PostgreSQL
- ⚽ **Sports Analytics:** Exploring football statistics and player performance
- 🌱 **Career direction:** Growing from analytics toward data engineering
- 📍 **Location:** Dar es Salaam, Tanzania
- 💼 **Availability:** Actively seeking suitable employment opportunities, including remote and on-site roles

### 🏠 2. Nashville Housing Data Cleaning

**Status: SQL cleaning completed · Dashboard planned**

**The story behind the data:** What can housing sales records tell us when inconsistencies, missing values, and duplicates are handled properly?

This PostgreSQL project transforms raw Nashville housing sales data into a cleaner, more consistent dataset ready for further analysis.

**Tools:** PostgreSQL, SQL, Git/GitHub.

**Key work:**
- Standardized date formats and data types
- Populated missing property addresses using SQL joins
- Standardized inconsistent land-use and vacancy values
- Identified and removed duplicate records
- Split property and owner addresses into separate fields
- Used validation queries to check data quality

**Next chapter:** Build a Tableau dashboard to investigate sale-price trends, property characteristics, and vacancy patterns.

[🏠 View the Nashville Housing project](https://github.com/johnsonnyimbo/nashville-housing-data-cleaning)
